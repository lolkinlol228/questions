# Fitness Survey Analytics v4 — сайт-опрос + расширенная админ-аналитика

Проект состоит из двух частей:

- `index.html` — публичная анкета. Респондент отвечает без регистрации и авторизации.
- `admin.html` — админ-панель с расширенной статистикой.

## Что изменено в v3

Админ-панель больше не ограничена несколькими готовыми таблицами. Теперь есть:

1. KPI по ответам, лидам, контактам, предоплатам, местной базе, женщинам, цене и локации.
2. Контроль квот перед инвестиционным решением.
3. Автоматические выводы по сильным лидам, возрасту, цене, услугам, барьерам и времени.
4. Готовые матрицы: возраст × цена, возраст × действие, язык × сегмент, сегмент × услуги, сегмент × барьеры, пол × приватность, локация × вероятность прийти и другие.
5. Конструктор статистики: можно выбрать любой вопрос в строках и любой вопрос в столбцах.
6. Подробная статистика по каждому вопросу отдельно:
   - общее распределение;
   - разбивка по языкам RU/KG/EN;
   - разбивка по возрастам;
   - разбивка по сегментам;
   - разбивка по полу;
   - разбивка по силе лида;
   - связь с ценой;
   - связь с действием до открытия;
   - для шкал — средние оценки;
   - для текстовых ответов — примеры и частые слова.
7. Экспорт CSV всех ответов.
8. Экспорт JSON всей аналитики.


## Supabase

1. Создайте проект в Supabase.
2. Откройте SQL Editor.
3. Выполните файл `supabase.sql`.
4. Создайте `.env.local` рядом с `package.json`.

Пример:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
VITE_ADMIN_REQUIRE_AUTH=true
VITE_SURVEY_VERSION=3
```

`anon key` не является секретным ключом. Он будет виден в браузере. Защита делается не через сокрытие anon key, а через Row Level Security в Supabase.

## Без регистрации для респондентов

Пользователь просто открывает сайт и отвечает. Аккаунт не нужен.

Защита от повторной отправки работает так:

- сайт сохраняет черновик в браузере;
- после отправки ставит локальную отметку;
- создаёт fingerprint устройства/браузера;
- Supabase запрещает повторную запись с тем же `survey_version + fingerprint_hash`.

Это блокирует обычные повторы с одного устройства. Абсолютно запретить повтор без аккаунта нельзя: человек может взять другой телефон, другой браузер или очистить данные.

## Кэширование незавершённых ответов

Анкета сохраняет черновик в `localStorage`. Если респондент случайно обновит страницу или закроет вкладку, ответы восстановятся, и он продолжит с того места, где остановился.

## Админ-панель без логина

По умолчанию админка защищена, потому что там могут быть номера телефонов и Telegram/WhatsApp.

Для локального закрытого теста можно поставить:

```env
VITE_ADMIN_REQUIRE_AUTH=false
```

И в `supabase.sql` раскомментировать политику public read. Для реального сбора ответов так делать нельзя.


## Что нового в v4

Добавлен мульти-конструктор статистики: можно выбрать сразу несколько параметров, например `язык → возраст → сегмент → цена → услуги`. Админка строит когорты и показывает по каждой группе количество людей, средний lead score, процент сильных лидов, контакты, предоплату, готовность к цене 2000+ сом, удобство локации, топ-услугу, топ-барьер и топ-время.

Обычный конструктор `вопрос × вопрос` оставлен для быстрых матриц и тепловых таблиц. Мульти-конструктор нужен для глубокого анализа аудитории.
